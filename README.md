# 📬 Site com Formulário usando Bootstrap

Este projeto consiste em uma página com um formulário de contato estilizado utilizando **Bootstrap 5**. A ideia principal foi praticar a criação de formulários modernos, responsivos e com boa usabilidade visual.

🔗 **[Acesse o site publicado aqui](https://site-com-formulario-em-bootstrap.vercel.app)**

---

## 🚀 Tecnologias Utilizadas

- HTML5
- CSS3
- Bootstrap 5

---

## ✨ Funcionalidades

- [x] Formulário de contato completo
- [x] Campos de validação como nome, e-mail, telefone e mensagem
- [x] Layout responsivo com grid do Bootstrap
- [x] Botão estilizado com feedback visual
